# 模板目录（视图层）

此目录就是前台的视图模板，**程序始终渲染这里的文件**（类似 ThinkPHP 的模板目录）。
启动时缺失的文件会以默认内容自动补齐，已有文件不会被覆盖。

直接用编辑器修改这里的文件即可，dev 模式保存后刷新浏览器立即生效；
后台「模板管理」的在线编辑读写的也是同一批文件，两者完全等价。

## 槽位与文件对应

| 文件 | 槽位 | 作用页面 |
|---|---|---|
| `site_header.hbs` | 全站页头 | 所有前台页面（LOGO/导航/会员区） |
| `site_footer.hbs` | 全站页脚 | 所有前台页面 |
| `global_css.css` | 全局样式 | 所有前台页面（纯 CSS，注入 `<style>`） |
| `home.hbs` | 首页区块 | `/` 主体内容 |
| `news_list.hbs` | 新闻列表 | `/news` 列表区域 |
| `post_detail.hbs` | 文章详情 | `/news/:slug` 正文区域 |
| `page_detail.hbs` | 单页内容 | `/page/:slug` |

## 语法（.hbs 文件，Handlebars）

- `{{post.title}}` 转义输出；`{{{post.contentHtml}}}` 原样输出 HTML
- `{{#each posts}}...{{/each}}` 循环；`{{#if cover}}...{{/if}}` 判断；`{{@first}}` 循环首项
- `{{formatDate post.publishedAt}}` 日期格式化
- 各槽位可用变量见后台「模板管理」编辑弹窗中的说明
- 模板里可以直接写 Tailwind 工具类，构建/开发时会自动扫描生成对应 CSS

## 其他操作

- 恢复默认：后台「模板管理」→「恢复默认」（用内置默认内容覆盖文件）
- 临时禁用：后台编辑弹窗关闭「启用此模板」（该槽位回退到内置 Vue 渲染）
